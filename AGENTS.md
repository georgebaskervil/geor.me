## Learned User Preferences

- Prefers autonomous dependency-rolling design that does not require routine human review.
- Treats browser console warnings (referrer-policy, Robustext SharedArrayBuffer, CORB on telemetry) as non-actionable when they are graceful degradation with no functional impact.
- Prefers direct execution for release tasks (commit, sync, push) once fixes are validated.
- Does not want large R2-hosted model files proxied through Rails; fix access with R2/Cloudflare CORS instead.
- When optimizing visual effects, preserve pixel-perfect appearance unless explicitly told otherwise.
- Text-shadow on all text and carousel slide blur are core design elements; do not remove them for performance work.
- Site blocks crawlers (`noindex, nofollow`); do not add SEO or robot-facing affordances.
- Live push updates should only fire when user-visible display fields change, not on every timer tick or timestamp refresh.
- CI image push and deploy (`build-push`) must never run on pull requests—only on push to `main`.
- When debugging UI locally, verify against `localhost:3000` rather than production (production will not reflect uncommitted changes).
- When committing, include all intended changes—not a partial subset unless the user explicitly scopes the commit.

## Learned Workspace Facts

- `geor.me` production/CI Docker builds run on Linux amd64, so `Gemfile.lock` must include `x86_64-linux` alongside local macOS platforms. Bun versions must stay aligned across `.bun-version`, `package.json` `packageManager`, and Dockerfile `BUN_VERSION` (currently 1.3.14); `bun.lock` drift blocks Docker builds (`bun install --frozen-lockfile` fails) — keep lockfile in sync after dependency changes. GitHub Actions: `build-push` in `.github/workflows/ci.yml` runs only on `push` to `main` (never on `pull_request`); CI `package-age-gates` enforces a 7-day minimum gem/bun age; Dependabot auto-merge requires repo secrets `APP_ID` and `APP_PRIVATE_KEY`; `gh pr merge` is immediate rebase; `scripts/wait-pr-checks-for-merge.sh` waits only on Socket and Snyk checks.
- The homepage Robustext embed is same-origin, must keep pointer/keyboard interactivity, and must be fully destroyed/re-instantiated via Stimulus `robustext-embed` on carousel slide mount/unmount (Emscripten breaks with inline scripts and cloneNode remounts).
- Page content renders inside a CRT barrel-filter stack (`.scanlines` outside; SVG `feDisplacementMap` on `#crt-content` and `.crt-shell` overlays inside `foreignObject`—not CSS `filter: url(#barrel)` on HTML, which misaligns `userSpaceOnUse`); Lenis smooth-scrolls the inner content. The custom cursor, Oneko, and click hearts live in `.crt-shell` inside the CRT filter (intentional design, not outside the warp); cursor and Oneko use `data-turbo-permanent` with saved state so they stay seamless across Turbo navigations. Site font: Waiting for the Sunrise via Google Fonts `<link>` in the layout (Cloudflare Fonts rewrites on geor.me); Pixelify Sans self-hosted for distraction-mode floating windows (`#distractionmode-scope .floating-window.window98`); Nabla self-hosted for the geor.me project footer. `loadFonts.js` uses the FontFace API for self-hosted woff2 and force-applies `font-family` on `.crt-shell` and `#crt-content` (Safari does not inherit web fonts from `html` inside SVG `foreignObject`). Do not use WebFont Loader with Vite `?url` SCSS font sheets—dev serves empty CSS and fonts fail to register.
- Legal/compliance paths (`/legal`, `/privacy`, `/licensing`, `/dmca`, `/credits`, `/doomdisclaimer`) 301 to `https://compliance.geor.me/books/georme-compliance-documentation` (and matching `/page/*` slugs); local controllers/views removed. Reusable geor.me project footer: `shared/geor_me_project_footer` partial plus self-contained embed at `/geor-me-project-footer.css` and `/geor-me-project-footer.html` (compliance links in `GeorMeProjectFooterHelper`; embed snippet may use Google Fonts with Cloudflare Fonts rewrite).
- App responses set COEP and COOP to `unsafe-none` site-wide so third-party iframe embeds work; Permissions-Policy blocks only obscure APIs (`payment`, `usb`, `hid`, `serial`, `midi`, `display_capture`, `sync_xhr`)—camera, microphone, gyroscope, and fullscreen are not blocked. Browser analytics/error tracking (Umami, Swetrix, Sentry client) is loaded via Cloudflare Zaraz, not the app bundle; `/data` still embeds the Umami share iframe. `georbreverse.geor.me` cannot be iframe-embedded from `geor.me` until that host drops `X-Frame-Options: SAMEORIGIN` and allows `frame-ancestors` (e.g. `https://geor.me`, `http://localhost:3000`).
- Distraction-mode ChatCCP uses `@mlc-ai/web-llm` (WebGPU) with `SmolLM2-360M-Instruct-q4f16_1-MLC`; weights download from Hugging Face via WebLLM (not R2, not Rails-proxied). Requires WebGPU (Chrome/Edge primary; Firefox often too slow).
- Distraction-mode HLS clips use intentional low-quality ("potato") encodes; shared defaults in `scripts/hls_encode_settings.sh` (426×240, CRF 34, ~350k cap); re-encode existing segments via `scripts/reencode_hls_potato.sh`.
- Lunar background texture (`lunar-texture.avif`) must be generated via Chromium/Playwright SVG capture plus `avifenc --lossless` (`bun run generate:lunar-texture`); CRT displacement map stays PNG for SVG `feImage` compatibility; `starfield.svg` and `turbo-loading-spinner.svg` live in `app/images/` (no CSS data-URI inlines; Vite does not re-inline `app/images` assets).
- Frontend assets: Stimulus controllers lazy-load via `import.meta.glob`; Phaser/Plotly load from `/public/vendor/` on demand via `loadVendorScript.js` (they crash the Vite transform pipe and cannot be bundled); ChatCCP WebLLM loads from `/vendor/web-llm/index.js` via `loadWebLLM.js` (`bun run sync:web-llm` copies `@mlc-ai/web-llm`—Rolldown cannot re-bundle its prebuilt `lib/index.js`); route CSS uses Vite SCSS entrypoints under `app/stylesheets/entries/` assigned in `RouteStylesheets#assign_route_stylesheets` as `@route_stylesheet_entries` and rendered after `core.scss` (with `data-turbo-track="reload"`); do not rely on `content_for` from controller `before_action` — it does not reach the layout here. Homepage route CSS includes embed partials; `/taskstack` uses `page-taskstack.scss` alone; Eclecticon routes share `entries/eclecticon.scss`; distraction mode loads only after the nav button via `distractionmode-launcher` and `data-distraction-deferred`. Production `vite:build` emits a Workbox service worker (`config/vite/pwa.js`, copied to `/service-worker.js`) that precaches Vite JS/CSS/fonts and runtime-caches same-origin static assets (not HTML, `/api/*`, or `/cable`). Turbo navigations use [`turbo-view-transitions`](https://github.com/palkan/turbo-view-transitions) when `<meta name="view-transition">` is present and `prefers-reduced-motion` is not `reduce`; `#site-main` has `data-turbo-transition="page"`. Without View Transitions, `turbo-loading` blur overlay still applies.
- Production Vite output (`public/vite` bulk) uploads to Backblaze B2 (`geor-me-assets`, prefix `vite/`, public read) during Docker build (`rake vite:upload_to_b2` with `B2_ASSETS_KEY_ID`/`B2_ASSETS_SECRET` BuildKit secrets); upload skips unchanged keys (size + `content_type`), re-uploads when B2 metadata is wrong, and prunes stale `vite/` objects. Bulky files are stripped from the image (manifests, `*.css`, CRT displacement map, and `/service-worker.js` stay). CSS must stay same-origin: root-relative `url(/vite/assets/…)` in a CDN-hosted stylesheet resolves against the CDN host and breaks backgrounds/fonts. When `VITE_ASSETS_B2_ENABLED=1` at runtime (Docker/Coolify ENV — not during `vite:build`), `config/environments/production.rb` sets `asset_host` to `https://geor-me-static.libreverse.io/file/geor-me-assets` so HTML tags emit CDN URLs; missing `/vite/*` requests redirect to the same CDN (no Rails proxy). Runtime needs no B2 credentials. GitHub secrets: `B2_ASSETS_KEY_ID`, `B2_ASSETS_SECRET` (build upload only). Homepage project carousel uses embed partials only (no HLS video slides).
- Blog posts (`/posts`) load from Prismic (`PrismicArticlesService`, types `blog_post` and `pdf-post` at `geor-me.cdn.prismic.io`); PDF posts redirect to Prismic-hosted media; structured text renders via `PrismicStructuredText` (local `app/articles/` markdown removed).
- Production/dev web server is Iodine (`bundle exec iodine`), not Puma; Docker and Procfile both start Iodine. Pin `iodine` 0.7.58 — 0.7.59's Linux C extension raises `TypeError` at runtime and during Docker `vite:build` (see `.snyk`); Dependabot must ignore all semver updates for iodine (auto-merge re-bumped it twice). Live footer/homepage counters use Action Cable (`LiveStatsChannel`, WebSocket at `/cable`) with `LiveStats` ticking on `Iodine.run_every` (no blocking Rack SSE); broadcasts only when `time_since` or `current_day` change, not every timer wake. Client is `app/javascript/live_updater.js` (`@rails/actioncable`, JSON poll fallback to `/api/v1/stats/live`). `config/cable.yml` uses `async` (single worker); scale with `redis` adapter + `REDIS_URL` when running multiple Iodine workers. `config/initializers/permessage_deflate.rb` tunes WebSocket compression for speed (`BEST_SPEED`, `HUFFMAN_ONLY`, 11-bit window) on small JSON frames.
